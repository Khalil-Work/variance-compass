# Verification evidence

How the suite proves the implementation against analytic ground truth,
what every tolerance means, and where the statistical limits are. Suite
state at the time of writing: **78 passed in 7.5 s** (Python 3.13,
NumPy 2.1.3, pytest 8.3.4; largest test sample size `N = 2**17`).

Run it yourself from the repository root:

```
pip install -r requirements-dev.txt
pytest
```

The results-script evidence (plots, GIF, CSV, JSON) is regenerated by
`python examples/run_verification.py`; the numbers quoted below come
from those runs and are deterministic for the documented seeds.

## Tolerance philosophy

All tolerances are **statistical bounds tied to the bootstrap standard
error (SE) of the estimator**, not cosmetic caps, and every fixed-seed
assertion is deterministic: the seed fixes every random draw, so the
observed error is an exact property of that seed, reproducible on any
machine with the same NumPy version. The rationale, in short:

* Index estimates are sample means of correlated products, so their
  error shrinks like `n^(-1/2)`; the row bootstrap of the design
  measures the spread empirically (SE) and a `> 3*SE` allowance covers
  the sampling distribution of the discrepancy.
* Where a test also asserts the *observed* error stays far below the
  statistical bound (e.g. `max < 0.006` against a 0.02 allowance), that
  number is the actually measured value for the documented seed.

### `tests/test_ishigami_analytic.py` -- the analytic ground truth itself

### `tests/test_estimators.py` -- estimator primitives

* `sample_mean` and `sample_variance` agree with `numpy.mean` /
  `numpy.var(ddof=...)` on identical samples to 1e-12 (relative),
  across sizes 1..1000 and ddof 0, 1, 3 -- the ddof convention is
  pinned explicitly.
* Split (`first_order_indices` / `total_effect_indices`) and combined
  (`saltelli_indices`) paths return bit-identical arrays.
* Failure modes verified: empty / 2-D / non-finite inputs, ddof too
  large, mismatched lengths, constant output (zero variance).

### `tests/test_sampling.py` -- the design itself

* Shapes, `U(0,1)` ranges, and the crossed-matrix structure
  (`crossed[i]` equals `A` except column `i`, which equals `B`'s;
  `A` unmutated).
* Bit-identical reproduction for a fixed seed; different seeds differ.
* `to_physical` maps `[0,1)` to the bounds correctly and validates them.
* Bad `n`/`dim`/`rng` types are rejected.

### `tests/test_validation.py` -- input validation

Every public entry point: non-callable models, non-integer / negative /
boolean sample sizes, malformed bounds (wrong shape, `low >= high`,
non-finite), bad seeds (negative, non-integer, string), missing
seed+rng, `RandomState` instead of `Generator`, bootstrap < 2, models
returning wrong shapes or non-finite output, empty/bad sweep grids,
empty/non-finite coefficients -- all raise `TypeError`/`ValueError`
with the documented messages.

## Statistical honesty

1. **Estimator bias and variance.** The Saltelli correlation estimators
   are consistent but not exactly unbiased at finite `n`: `V_hat` uses
   an estimated mean (`O(1/n)` bias), and the products in the
   estimators inherit finite-sample correlation. The bootstrap SE
   measures the sampling spread; it does not remove bias. At the sizes
   used here the observed fixed-seed errors (0.002-0.006) are of the
   same order as 1-2 bootstrap SEs, i.e. consistent with an unbiased
   estimator; the suite's >3-sigma allowances cover this honestly.
2. **Bootstrap caveats.** The row bootstrap resamples design rows, so
   it captures the dominant Monte Carlo variability, but percentile
   intervals from `B = 100..200` replicates are themselves noisy, and
   any resampling-based CI understates far-tail risk. Do not read the
   95% intervals as exact coverage guarantees.
3. **Fixed-seed determinism.** For a documented seed, every number in
   the suite and the results script is exactly reproducible (same
   NumPy version); "observed: 0.0053"-style values in test comments are
   measurements, not targets. Different seeds give different estimates
   -- the cross-seed tests pin the expected spread, not a single value.
4. **What is NOT claimed.** No claim is made about convergence rates
   beyond the observed `n^(-1/2)` SE scaling; the quadrature checks use
   trapezoidal grids (0.2% agreement), not adaptive high-precision
   integration; and the analytic Ishigami indices are exact only for
   the stated parameter values `a = 7`, `b = 0.1` and `U(-pi, pi)`
   marginals.
